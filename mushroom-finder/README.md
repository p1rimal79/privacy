# Mushroom Finder — isolated draft documentation

This directory belongs to the Mushroom Finder prototype. Existing Kliov pages are independent.

Privacy, Terms and Support are bilingual drafts, version 0.1.2. No operator identity or private contact is inferred from the repository owner or Kliov. The linked GitHub Issues channel is public; private photographs and exact locations should not be posted.

The app processes camera frames locally, has no species classifier, stores private notes and optional phone/manual locations locally, and bundles a geographic overview and reference media. Optional explicit Geofabrik map downloads are the app network operation. Training-data collection is a separate developer tool with separate media/observation license checks.

These files are on a feature branch. GitHub Pages URLs are not claimed to be live. Production publication requires operator/legal review and actual iPhone/model verification.
