# Mushroom Finder — research documentation 0.1.3

Latest measured experiment: [species evaluation](analysis/species-evaluation-0.1.3.md). A real 30-class plus unknown model is trained/exported and integrated into the separate native Research project for single-mushroom photo selection. Community labels are unreviewed; model quality and native runtime are not production approved. Live-video species analysis remains disabled pending physical-device tests.

Privacy, Terms and Support are bilingual drafts. Operator identity and private contact are unconfirmed. Existing Kliov pages are independent. The public GitHub Issues support channel is unsuitable for private photographs or exact locations.

This repository contains legal drafts, analysis and reproducible collection/training/export code. Native source, model weights and photo material are delivered separately; raw datasets and private test photographs are not committed.

Pages deployment, public release and App Store readiness are not claimed. The older 0.1.2 analysis documents the reference/data collection baseline.
